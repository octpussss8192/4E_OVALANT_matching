OVERTER WATCH2026 運用マニュアル・取扱説明書

高専祭 3v3 赤外線シューティングゲーム「OVERTER WATCH2026」の予約・マッチングシステム取扱説明書です。
当日の受付・進行スタッフは、本書の内容を確認の上オペレーションを行ってください。

1. システム概要と3つの画面

本システムは、用途に合わせて 3つの画面 に分かれています。

画面名 URL 主な利用者 主な役割
参加者画面 / 一般来場者（スマートフォン） エントリー受付、整理券番号・呼出状況の確認
会場モニタ /monitor 待機列・一般来場者（大型ディスプレイ） 現在対戦中・次回呼出・次々回準備枠の表示
運営ダッシュボード /admin 受付・進行スタッフ（PCまたはiPad） 試合進行（案内完了・終了）、不在スキップ、復帰

2. 当日の全体オペレーションの流れ

[参加者] スマホで受付 → 整理券発行（待機中）
                                ↓
[モニタ] 試合スロットに自動割当（3. 次々回準備枠）
                                ↓
[モニタ] 呼出枠に昇格（2. 次の試合・受付呼出中）
[参加者] スマホ画面が「呼出中」に変化 ＆ バイブレーション通知
                                ↓
[スタッフ] 参加者が受付に来たら画面を確認し「案内完了」を押す
                                ↓
[スタッフ] フィールドでの試合（8分または10分）
                                ↓
[スタッフ] 試合終了時に「試合終了」を押す（スロットが自動繰り上げ）

3. 参加者（プレイヤー）の画面とルール

① 受付手順

来場者は受付のQRコードをスマートフォンで読み取り、以下の情報を入力してエントリーします。

  1. チーム名
  2. 代表者名
  3. 参加人数（1〜6名）
  4. 対戦モード（合流戦 / 貸切戦）

【人数の安心ルール（友だち分断防止）】

  • 4〜6名: 友だち同士で戦える「貸切戦（所要時間8分）」が自動選択されます。
  • 1〜3名: 他のグループと組む「合流戦（所要時間10分）」または「少人数貸切戦」を選択できます。
    ※グループメンバーが敵味方に分断されることは絶対にありません。

② 整理券画面のステータス変化

エントリーが完了すると、整理券番号が表示されます。

  • 待機中: 前の待機組数と予想待ち時間が表示されます。
  • 次々回 試合枠 (まもなく呼出): 次の枠に入った合図です。受付付近へ移動を促します。
  • 呼出中 (受付へお越しください): 端末が1回振動し、画面が強調表示されます。画面消灯防止（WakeLock）が自動で働きます。
  • 対戦中: フィールドへ入場中の状態です。
  • 不在スキップ: 呼出時に不在だったため無効化された状態です。遅れて来場した場合は受付スタッフへ申し出るよう案内されます。

※ブラウザを閉じたり誤って再読み込みした場合でも、再アクセスすれば同じ整理券画面が自動復元します。

4. 会場モニタ（/monitor）の設置と見方

会場のプロジェクターや大型液晶ディスプレイに全画面（F11キー）で表示しておきます。

  • 1. 現在対戦中（左枠）: フィールド内で試合を行っているチーム名と整理券番号
  • 2. 次の試合・呼出中（中央枠）: 受付に呼び出し中のチーム名
  • 3. その次の試合（右枠）: まもなく呼出となる準備枠
  • 助っ人表示: 奇数人数などでプレイヤーが不足する場合、システムが自動で「運営スタッフ助っ人」枠を割り当て、必ず 3 vs 3 の対戦が維持されます。

5. 運営スタッフ画面（/admin）の操作手順

受付・進行席のPCまたはiPadで /admin を開きます。

基本操作（ボタンを押すだけ）

1. 呼出中の参加者が受付に揃ったら

👉 「案内完了」 ボタンを押す

  • 呼出中だった枠が「現在対戦中」へ昇格します。
  • 参加者をフィールド内の装備・ブリーフィングエリアへご案内ください。

2. フィールド内の試合が終了したら

👉 「試合終了」 ボタンを押す

  • 対戦中だった枠が「対戦完了」となり、フィールドが空きます。
  • 次の試合枠が自動的に繰り上がり、待機列から新しい対戦枠が自動編成されます。

3. 呼出しても受付に来ない場合（不在スキップ）

👉 該当グループの 「不在スキップ」 ボタンを押す

  1. 確認モーダルダイアログが表示されます。チーム名と整理券番号を確認して「スキップを実行する」を押します。
  2. スキップされたグループは枠から除外されます。
  3. 相方グループの保護: 同じ枠にいた相手チームや相方グループは、待機列の最優先に戻るか、スタッフ助っ人を補充して枠が自動維持されます。

【重要】遅れて来場した参加者の「復帰（救済）」手順

呼出時に不在で一度スキップされたグループが、「遅れてしまいましたが参加できますか？」と受付に来た場合の対応手順です。

  1. 運営画面の下段にある 「不在スキップ」 タブ（または「全履歴」タブ）を開きます。
  2. 該当する整理券番号を探します（ステータスが 不在スキップ と赤く表示されています）。
  3. 行の右端にある 「復帰」 ボタンを押します。
  4. 確認モーダルダイアログが表示されるので、「待機列に復帰させる」 を押します。
  5. 👉 復帰完了: そのグループは**待機列の先頭（最優先）**に差し戻され、次の空き枠に最優先で割り当てられます。参加者には「まもなくお呼び出ししますので、受付付近でお待ちください」とお伝えください。

※二重エントリー防止ガード
参加者がスキップ後にすでにスマホから新しい整理券を取り直していた場合、復帰ボタンを押すと「同一参加者が既に整理券 #XXX で受付中のため復帰できません」と警告され、二重エントリーが自動的に防止されます。

その他の管理機能

  • CSVエクスポート:
    上部の「CSV出力」ボタンを押すと、本日の全エントリー履歴（整理券番号、チーム名、代表者名、人数、受付時刻、完了ステータス等）をExcel対応UTF-8（BOM付き）でダウンロードできます。
  • 全データ初期化（全リセット）:
    朝の準備・リハーサル終了後、本番開始前にデータをゼロに戻す場合は「全リセット」を押します（確認ダイアログが出ます）。

6. よくある質問・トラブルシューティング

Q1. 呼んでも誰も来ない場合はどうすればいいですか？

A. 「不在スキップ」を押してください。枠に残された他のグループは待機列の最優先に戻るため、不公平なく次の試合に案内されます。

Q2. スキップした後に「遅れました」と本人が来ました。

A. 運営画面下段の「不在スキップ」タブから、該当チームの「復帰」ボタンを押してください。待機列の先頭に戻り、次の枠ですぐに呼び出されます。

Q3. 3人チーム vs 2人チームで人数が合わない場合は？

A. そのままで大丈夫です。システムが自動で「運営スタッフ助っ人」を1名割り当て、3 vs 3 の試合として進行します。受付スタッフ1名が助っ人として銃を持ってご参加ください。

Q4. 参加者が誤ってスマホのブラウザを閉じてしまいました。

A. もう一度同じ受付QRコードを読み込むかURLを開いてもらってください。端末に保存されたセッション情報から、元の整理券画面が自動的に再表示されます。

Q5. 参加者のスマホが電波不良・充電切れになりました。

A. 運営画面（/admin）の全エントリー一覧から代表者名で検索し、整理券番号をお伝えください。口頭呼出でそのまま対戦へご案内可能です。

7. 事前テスト・リハーサル手順（ローカル環境）

本番データベースに接続せず、PC単体で安全に動作確認を行う手順です。

バックエンド起動（ローカルモード）

$env:LOCAL_MODE="1"
$env:USE_LOCAL_STORAGE="true"
$env:PYTHONIOENCODING="utf-8"
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000

※画面上部に「ローカル検証モード (本番DB保護中)」と表示され、本番DBには一切書き込まれません。

フロントエンド起動

別ターミナルで実行：

cd frontend
npm run dev

ブラウザで http://localhost:3000（参加者）、http://localhost:3000/admin（運営）、http://localhost:3000/monitor（モニタ）を開いてテストできます。

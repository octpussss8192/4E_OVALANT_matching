# 3x3 サバゲーマッチングシステム (4E_OVALANT_matching)

3 vs 3（6名対戦）の厳密な成立を最優先とするサバイバルゲームフィールド向けマッチングエンジンおよびCLIデバッガーです。  
来場グループの人数・希望（通常/貸切）に応じたビンパッキング、3名 vs 3名のグループ分割編成、3枠スロット管理、サジェスト表示、不在スキップなどの機能を備えています。

---

## 📋 主な機能と特徴

1. **3 vs 3（3名チーム対戦）の完全厳守**
   - すべての試合で **Red 3名 vs Blue 3名（計6名）** を厳密に編成します。
   - 5名以下での不完全なマッチ（3 vs 2など）は行わず、必ず合計6名が集まるまで待機します。
2. **グループ分割による柔軟な 3名チーム編成**
   - 4〜5名のグループがOpenエントリーした場合でも、グループを分割（例: 4名組ならRed 3名とBlue 1名）して直ちに「3 vs 3」を成立させます。
   - 分割時も、元のグループの分断人数が最小になるよう最適配分します（分割なしで3名が作れる場合は分割しません）。
   - モニタ画面・CLIでは `[Red: チームA(3名) vs Blue: チームA(1名) + チームB(2名)]` のように分割内訳が明示されます。
3. **貸切（Closed）も「ちょうど6名」限定**
   - 仲間内での3 vs 3対戦を担保するため、貸切希望も「ちょうど6名」のグループのみ受け付けます。
   - 貸切試合は通常（10分）より短い8分に自動短縮されます。
4. **3段階のスロット管理**
   - `Current（進行中）`: 現在フィールド内でプレイ中の試合。
   - `Next（呼出中）`: 次にフィールドへ入る準備を行う試合。
   - `Next Next（待機）`: 次々回の試合。
5. **到着順（FIFO）最優先**
   - 待機列の先頭グループを優先し、待ち時間を最小化します。
6. **サジェストTips自動生成**
   - 待機列状況から「現在【〇名】組なら、すぐにご案内可能です！（3vs3即時成立）」とモニタに表示する案内を自動計算します。
7. **運営不在スキップ & 自動再編**
   - 呼出時に不在だったグループをスキップ（無効化）。残った待機グループを即座に再計算して後続枠へ繰り上げます。

## 🛠️ 必要環境

- **Node.js**: v22.6.0 以上推奨（TypeScriptネイティブ実行 `--experimental-strip-types` を利用）
- **npm**

---

## 🚀 セットアップ

リポジトリ直下で依存関係をインストールします:

```bash
npm install
```

---

## 💻 実行方法

プロジェクトには **自動シナリオテストモード** と **対話型CLIモード** の2つの実行方法があります。

### 1. シナリオ検証（自動テスト実行）

全6種類の主要シナリオ（分割なし3vs3、貸切6名と通常、サジェストTips、4名組分割3vs3、不在スキップ、5名組分割3vs3）を順番にシミュレーション実行します。

```bash
npm test
```
または
```bash
node --experimental-strip-types src/cli.ts
```

### 2. 対話型CLI（インタラクティブ操作）

受付や試合進行、モニタ確認を対話形式で操作・確認できます。

```bash
npm run interactive
```
または
```bash
node --experimental-strip-types src/cli.ts --interactive
```

---

## 🎮 対話型CLIの使い方

対話型CLIを起動すると、以下のメニューが表示されます:

```text
======================================================
🎮 3x3 サバゲーマッチングシステム 対話型CLI
======================================================
コマンド一覧:
  1: グループ新規エントリー (受付)
  2: 現在の待機・スロット状況を表示 (モニタ画面)
  3: 試合を1サイクル進める (Advance Match)
  4: 運営スキップ (不在グループの無効化)
  5: グループ一覧・ステータス詳細
  6: サンプル待機データを自動生成投入
  0: 終了
------------------------------------------------------
```

### 各コマンドの説明

| コマンド | 名称 | 説明 |
| :---: | :--- | :--- |
| **`1`** | **グループ新規エントリー** | チーム名・代表者名・人数（1〜6名）・希望（Open / Closed）を入力して受付登録します。貸切（Closed）は6名のみ受け付けます。 |
| **`2`** | **待機・スロット状況表示** | 「進行中 (Current)」「呼出中 (Next)」「待機中 (Next Next)」の各スロットと、チーム内訳（Red 3名 vs Blue 3名）、全体の待機状況、サジェストTipsを表示します。 |
| **`3`** | **試合を1サイクル進める** | 進行中の試合を「終了」にし、NextをCurrentへ、Next NextをNextへとスロットを繰り上げます。 |
| **`4`** | **運営スキップ** | 呼び出し時に不在だったグループを選択してスキップ。該当グループを無効化し、後続グループを繰り上げて再マッチングします。 |
| **`5`** | **グループ一覧詳細** | 登録されている全グループの整理券番号、状態（waiting / called / in_match / completed / skipped）、予想待ち時間などを一覧表示します。 |
| **`6`** | **サンプルデータ投入** | 動作確認用のグループ（Alpha 3名, Bravo 2名, Charlie 1名, Delta貸切 6名）をまとめて登録します。 |
| **`0`** | **終了** | CLIを終了します。 |

## ⚙️ システム設定カスタマイズ (`SystemConfig`)

`MatchingEngine` の初期化時に以下の設定値を上書きできます（[src/matchingEngine.ts](file:///c:/college_Stamps/新しいフォルダー/4E_OVALANT_matching/src/matchingEngine.ts)）:

```typescript
const engine = new MatchingEngine({
  maxPlayersPerMatch: 6,              // 1試合の合計人数 (3 vs 3 = 6名)
  standardMatchDurationMinutes: 10,   // 通常試合の所要時間 (分)
  closedMatchDurationMinutes: 8,      // 貸切試合の所要時間 (分)
  turnaroundDurationMinutes: 2,       // 転換・インターバル時間 (分)
});
```

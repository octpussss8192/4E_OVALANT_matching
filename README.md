# 🎮 3x3 サバゲーマッチングシステム (Python版)

3 vs 3（6名対戦）の厳密な成立を最優先とするサバイバルゲーム向けマッチングエンジンです。  
外部ライブラリ不要（Python標準ライブラリのみ）で動作し、**アルゴリズムの改造・実験が直感的に行えるように設計**されています。

---

## 📁 整理されたプロジェクト構成

```text
4E_OVALANT_matching/
├── main.py              # 🚀 メインエントリー（シナリオ実行 / CLI起動）
├── matching_engine.py   # ★【最重要】マッチング・チーム分けアルゴリズム本体
├── models.py            # 📦 データ構造定義（グループ、試合、チーム等）
├── scenarios.py         # 🧪 検証シナリオ集（テストケース）
├── cli.py               # 💬 対話型シミュレーションCLI
├── README.md            # 📖 本ドキュメント
└── typescript/          # 🗄️ 旧TypeScript版（参考・退避用）
```

## 💡 アルゴリズムの改造ガイド (どこを弄ればいい？)

アルゴリズムのロジックはすべて **[`matching_engine.py`](matching_engine.py)** に集約されています。  
目的別に対応する関数を直接書き換えるだけで、簡単にオリジナルのマッチングルールを試せます。

### ① 待機列から「誰と誰をマッチさせるか」を変えたい場合
👉 **`matching_engine.py` の `find_next_match()`**
* 現在は **FIFO（到着順）最優先** で、最も長く待っているグループを核にして合計6名になる組み合わせを探索しています。
* **改造例**:
  - 「待ち時間が長い人を最優先で優遇する」
  - 「ソロプレイヤー同士を優先して集める」
  - 「待機時間に応じて人数条件を調整する」

### ② 選ばれた6名を「どう赤・青チームに分けるか」を変えたい場合
👉 **`matching_engine.py` の `assign_teams()`**
* 現在は **3名 vs 3名** を完全厳守し、4名や5名グループがいる場合はグループを分割（例: 4名組ならRedに3名、Blueに1名）して配分しています。分割なしでジャスト3名が作れる場合は仲間同士を分断しません。
* **改造例**:
  - 「友達同士で対戦できるよう、あえて4名グループを2名・2名に均等分割したい」
  - 「レーティングや勝率を持たせてチームの強さを均等にしたい」

### ③ 待機モニタの「案内サジェスト」を変えたい場合
👉 **`matching_engine.py` の `calculate_suggestion()`**
* 現在は「あと何名のエントリーがあれば即座に 3 vs 3 が成立するか」を算出してTipsメッセージを生成しています。

### ④ 新しい実験シナリオを追加したい場合
👉 **[`scenarios.py`](scenarios.py)**
* `scenario_7_my_experiment()` のように関数を1つ作成し、最後に `run_all_scenarios()` に追加するだけで即座にテストできます。

## 📋 対話型CLIの使い方 (`cli.py`)

```text
========================================================
🎮 3x3 サバゲーマッチングシステム 対話型CLI (Python版)
========================================================
コマンド一覧:
  1: グループ新規エントリー (受付)
  2: 現在の待機・スロット状況を表示 (モニタ画面)
  3: 試合を1サイクル進める (Advance Match)
  4: 運営スキップ (不在グループの無効化)
  5: グループ一覧・ステータス詳細
  6: サンプル待機データを自動生成投入
  0: 終了
--------------------------------------------------------
```

* **`1` 新規エントリー**: チーム名・代表者名・人数（1〜6名）・希望（通常/貸切）を入力。貸切（Closed）は3vs3厳守のため6名限定です。
* **`2` 待機モニタ**: 「進行中 (Current)」「呼出中 (Next)」「待機中 (Next Next)」の各スロットと、チーム内訳（Red 3名 vs Blue 3名）、全体の待機数、サジェストを表示します。
* **`3` 試合進行**: Currentが終了し、Next ➔ Current、Next Next ➔ Next へとスロットが繰り上がります。
* **`4` 運営スキップ**: 呼び出し時に不在だったグループを無効化し、後続グループを即座に再編・繰り上げます。
* **`6` サンプル投入**: 動作確認用のグループ4組を一括投入します。

## 📦 データモデルの確認 (`models.py`)

* 各データは `@dataclass` で定義されているため、辞書のキーではなく `group.team_name` や `match.status` のように属性として直感的にアクセスできます。

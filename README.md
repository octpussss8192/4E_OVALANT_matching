# 🎮 3x3 サバゲーマッチングシステム (Python版)

3 vs 3（6名対戦）の成立を最優先とするサバイバルゲーム向けマッチングエンジンです。  
外部ライブラリ不要（Python標準ライブラリのみ）で動作し、**アルゴリズムの改造・実験が直感的に行えるように設計**されています。

---

## 🌟 最新のアルゴリズム機能 & 改善点

1. **チーム分けバグの完全修正**:
   - `2名×3組` や `4名+2名` など、どんな人数構成でも正確に **[Red 3名 vs Blue 3名]** を編成。
2. **3/2マッチの許可 & 運営スタッフ助っ人補充**:
   - プレイヤーが合計5名の場合、**3名 vs 2名** でのマッチを許可！
   - 足りない1名は**「運営スタッフ（シフトから助っ人参加）」**として補充され、フィールド内は完全な「3 vs 3」として即座にゲーム開始できます。
3. **不在スキップ時の即時再探索 & 再マッチング**:
   - 呼出時に不在だったチームをスキップした際、残された相方チームを待機列の先頭に戻し、**即座に後続グループと再マッチング（6名または5名+スタッフ）**して新しい試合を編成します。
4. **先頭詰まり（Head-of-Line Blocking）の防止**:
   - 先頭グループが人数待ちの状態でも、後続グループ同士で試合が作れる場合は「追い越しマッチング」を行い、フィールドを空っぽにしません。

## ⚡ クイックスタート (すぐ動かす)

Python 3.10以上があれば、追加の `pip install` なしですぐに実行できます。

### 1. シナリオテストを一括実行（アルゴリズム動作確認）
```bash
python main.py
```

### 2. 対話型CLIで手動シミュレーション
```bash
python main.py --interactive
```
*(短縮形: `python main.py -i` または `python cli.py`)*

### 3. バグ修正・エッジケースの検証テスト
```bash
python test_edge_cases.py
```
